# ترحيب محراب (mihrab-welcome)

امتداد **الطبقة 1** (إضافة محزومة، بلا رُقعة نواة) يوفّر تجربة الإعداد الأوّل في محراب:

- **جولاتٌ عربيّة** (`contributes.walkthroughs`) — «محرابُك عربيّ» (الاتّجاه والخطّ والمشاركة)، وجولةُ المتصفّح، و«جئتَ من VS Code؟». تُفتَح الأولى مرّةً عند أوّل إقلاع.
- **حرّاسُ الاتّجاه** — كاشفُ قلبِ الاتّجاه وإصلاحُه [BS-01]، وتسميةُ محارفه [BS-02]، وحارسُ أسماء الملفّات [BS-03]، و«انسخ للنشر» [BS-04].
- **المساعدةُ داخل المحرّر** [ON-03]، واستيرادُ إعدادات VS Code [MG-01]، وخبرُ الإصدار الأحدث [ON-04]، والتصديرُ للطباعة [PR-01].

## البنية

- `package.json` — المانيفست (الأوامر + الجولات + activationEvents).
- `extension.js` — نقطةُ الدخول (CommonJS، بلا خطوة بناء؛ يُشحن كامتداد مدمج)، والوحداتُ بجوارها.
- `media/*.md` — محتوى خطوات الجولة (RTL).
- `help-panel.js` — لوحة «مساعدة محراب» (`Alt+F1`): تبويبا المصطلحات والاختصارات ببحثٍ عربيٍّ مطبَّع.
- `data/*.json` — المسرد والاختصارات، **تُولَّد** من `site/data/` عند كلّ حزم (‏`build/lib/help_data.py`) ولا تُحفَظ هنا [ON-03]. لتشغيل الامتداد من المصدر (‏`--extensionDevelopmentPath`) ولّدها أوّلًا بـ`python build/lib/help_data.py`، وإلّا فلوحةُ المساعدة فارغة. في `keybindings.json` حقلُ `note` اختياريٌّ يُعرَض سطرًا باهتًا تحت اسم الأمر — في الصفحة وفي اللوحة معًا.

كلّ نصّ ظاهر للمستخدم ثابتٌ مسمًّى في وحدته (نسخة عربيّة-أوّلًا)، ومعرّفاتُ الأوامر ثوابتُ
مسمّاة لا سلاسلُ حرفيّةٌ موضعيّة.

## قرار التعريب (i18n)

عناوين الأوامر ووصف خطوات الجولة تُكتب **عربيّةً مباشرةً** في `package.json` بلا
`package.nls.*` ولا مسار `en` — قرار **«عربيّ-أوّلًا»** مقصود يطابق قرار المستودع الموثَّق
(حزمة اللغة `language-pack-ar` تُعرِّب سطح المنبع؛ و`package.nls.ar` يُتجاوَز مع حزمة لغة
نشطة، فالحقن يكون في محتوى الحزمة). إن صار الهدف لاحقًا ثنائيّ اللغة، يُضاف
`package.nls.json` (إنجليزيّ افتراضيّ) + `package.nls.ar.json`، وتُستبدَل العناوين الحرفيّة
بمفاتيح `%key%`. هذا **دَينٌ مؤجَّل واعٍ** لا سهوٌ.
