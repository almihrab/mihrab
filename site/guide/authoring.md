# كتابة المحتوى

> لمن يضيف صفحةً أو يترجمها أو يعدّلها، أو يعدّل المسرد والاختصارات ونصّ الصفحة الأولى، أو يضيف إلى المولِّد صفحةً أو أصلًا.
> ← [فهرس الموقع](../README.md)

## أضف صفحة

متى: صفحةُ توثيقٍ جديدة، مترجَمةٌ من صفحةٍ في `vscode-docs`.

1. أنشئ `site/content/<الاسم>.md`. الاسمُ لاتينيٌّ قصير، وهو مسارُ الصفحة على الشبكة (`/<الاسم>/`).
2. اكتب في أوّله الترويسة ([الحقول](#الترويسة))، واكتب `source_sha: ""` فارغًا.
3. أضف الصفحةَ إلى `NAV` في `site/sitegen/data.py`، تحت أحد الأقسام، بعنوانها العربيّ. العنوانُ يأتي من هنا لا من الملفّ.
4. املأ البصمة، وهذا يحتاج شبكة:
   ```bash
   python tests/docs/check_drift.py --seed
   ```
5. ابنِ وافحص:
   ```bash
   python tests/docs/check_drift.py --offline
   python tests/docs/check_site.py
   ```

تحقّق: يمرّ الفحصان، وتظهر الصفحةُ في التنقّل وفي البحث.

⚠️ أضف الملفَّ وسطرَ `NAV` معًا: صفحةٌ بلا سطر، أو سطرٌ بلا ملفّ، يوقف البناءَ برسالة.

⚠️ ابدأ المتنَ بعنوان `##`: العنوانُ الأوّل من `NAV`، والبناءُ يرفض `#` في المتن.

⚠️ شغّل `--offline` بعد `--seed` دائمًا: بلا شبكةٍ يبقى `source_sha` فارغًا و`--seed` يخرج بنجاح، و`check_site.py` لا يكشف ذلك.

لماذا ثلاثةُ أقسامٍ فقط؟ ← [ق-05](decisions.md#ق-05--ثلاثة-أقسام-في-التنقل)

## عدل صفحة

متى: تصحيحٌ في صفحةٍ قائمة، أو تحديثٌ لترجمتها بعد تغيّر منبعها.

1. عدّل `site/content/<الاسم>.md`.
2. إن حدّثتَ الترجمةَ لتطابق المنبع، فحدّث `translated_at`، واجعل `source_sha: ""`، وشغّل `check_drift.py --seed`.
3. شغّل `python tests/docs/check_site.py`.

تحقّق: يمرّ الفحص، و`check_drift.py` لا يرفع رايةَ انجرافٍ للصفحة.

## الترويسة

تبدأ كلُّ صفحةٍ بحقولها الأربعة. ويفرض `check_drift.py` منها `source_path` و`source_sha`:

```yaml
---
description: سطرٌ واحد للفهرسة والبحث.
source_path: docs/editing/codebasics.md    # صفحةُ المنبع، وهي شرطُ النِسبة في CC BY
translated_at: 2026-08-01
source_sha: "…"                            # بصمةُ ملفّ المنبع وقتَ الترجمة
---
```

وحقلٌ خامسٌ اختياريّ: `drift: major` يُظهر أعلى الصفحة لافتةً بأنّ منبعها تغيّر كثيرًا ولم تُحدَّث ترجمتُها بعد.

ويقارن `check_drift.py` البصمةَ بالمنبع:

```bash
python tests/docs/check_drift.py --seed     # يكتب البصمةَ في الصفحات الخالية منها (يحتاج شبكة)
python tests/docs/check_drift.py            # يقارن بالمنبع ويرفع رايةَ الانجراف (يحتاج شبكة)
python tests/docs/check_drift.py --offline  # اكتمالُ الحقول فقط، بلا شبكة
```

لماذا بصمةٌ في كلّ صفحة؟ ← [ق-06](decisions.md#ق-06--بصمة-المنبع-في-كل-صفحة)

## Markdown المدعوم

مجموعةٌ مضبوطة:

- عناوين `##` و`###`
- فقرات، وقوائم، وجداول
- كتلُ كودٍ مسيَّجة، وكودٌ سطريّ
- روابط، و`**عريض**`
- اقتباسٌ `>`، ويُصيَّر لافتةَ قيد، مثل «هذه الصفحةُ عن نسخة المكتب»

⚠️ اكتفِ بهذه. `#` يوقف البناء، وما عداه يمرّ نصًّا حرفيًّا بلا تنبيه: `####` فقرةٌ تبدأ بالعلامات، و`*مائل*` نجومٌ ظاهرة، و`![]()` علامةُ تعجّبٍ ثمّ رابط. افتح الصفحةَ بعد البناء وانظر.

### الاختصار

```
{{Ctrl+Shift+P}}
```

يُصيَّر حاويةً معزولةَ الاتّجاه (`unicode-bidi: isolate`).

⚠️ اكتب كلَّ اختصارٍ داخل `{{…}}`، لا نصًّا عاديًّا: خوارزميّةُ الاتّجاه تنقل `+` أو تعيد ترتيبَ الرموز في الجملة العربيّة، فيُعرض الاختصارُ خطأً.

## حدث المسرد أو الاختصارات

متى: مصطلحٌ جديدٌ أو بديلٌ ممنوع، أو اختصارٌ يُضاف إلى صفحة `/keyboard/` أو يُصحَّح.

- **المسرد:** `site/data/glossary.json`. فيه لكلّ مصطلحٍ لفظُه المعتمد وبدائلُه الممنوعة.
- **الاختصارات:** `site/data/keybindings.json`، ومنه تُبنى صفحةُ `/keyboard/`.

1. عدّل الملفّ.
2. شغّل الفحصين:
   ```bash
   python tests/docs/check_site.py
   python tests/static/lint_patchers.py
   ```

تحقّق: يمرّ الفحصان. ولوحةُ المساعدة في المحرّر تأخذ الملفّين نفسَيهما عند البناء، فلا نسخةَ تُحدَّث يدويًّا ([ON-03](checks.md#حراس-من-خارج-الموقع)).

ويمسك `lint_patchers.py` كذلك أيَّ بديلٍ ممنوعٍ في `content/`، إلّا ما اقتُبس بين «» من نصّ الشاشة.

## عدل نص الصفحة الأولى

متى: تغييرُ نصٍّ في الصفحة الأولى، لا تصميمِها.

1. عدّل `site/data/site.json`.
2. شغّل `python tests/docs/check_site.py`.

تحقّق: يمرّ الفحص، وتعرض `site/public/index.html` النصَّ الجديد.

لماذا النصُّ ليس في بايثون؟ ← [ق-08](decisions.md#ق-08--النص-التسويقي-في-البيانات)

## أضف صفحة مولدة أو أصلا

متى: صفحةٌ لا تأتي من `content/`، أو ورقةُ أنماطٍ أو سكربتٌ جديد.

حسب الحالة:

- **صفحةٌ مولَّدة:** اكتب دالّتها في `sitegen/pages.py`، واستدعِها من `main()` في `build.py` بـ`write()`. إن كانت إلزاميّة فأضفها إلى قائمة `required` في `site_guard/out.py`.
- **ملفٌّ في جذر `site/assets/`:** يُنسخ إلى المخرَج وحده، وتُجرَّد تعليقاتُه إن كان CSS أو JS. أضف سقفَه المضغوط إلى `_GZ_CAP` في `site_guard/out.py`، فبلا مدخلٍ فيه لا يُفحص حجمُه ([MIN-02](checks.md#بنية-المولد-والمخرج)).
- **مجلّدٌ فرعيّ في `site/assets/`:** لا يُنسخ إلّا ما سُمّي في حلقة `for sub in` بـ`build.py`، وغيرُه يُتخطّى بصمت. أضف اسمَه إليها.
- **أصلٌ يولّده البناء:** أعلنه في `_GENERATED` في `site_guard/out.py`، وإلّا حسبه [OUT-03](checks.md#بنية-المولد-والمخرج) ملفًّا بلا مصدر.

ثمّ:

1. أضف صفَّه إلى [خريطة الملفّات](../README.md#خريطة-الملفات).
2. شغّل `python tests/docs/check_site.py`.

تحقّق: يمرّ الفحص، ويظهر الملفُّ في `site/public/`.

لماذا تُجرَّد التعليقات؟ ← [ق-10](decisions.md#ق-10--تعليقات-المصدر-لا-تشحن)

## أسلوب الكتابة

### المصطلحات

- خذ كلَّ مصطلحٍ من `data/glossary.json`، في المحتوى وفي هذا الدليل.
- اقتبس اسمَ الأمر أو الزرّ أو التبويب **كما تعرضه الشاشة** بين «»، ومعه «(هكذا اسمُه في الواجهة)». والنثرُ حوله بلفظ المسرد.

لماذا قد يخالف لفظُ الشاشة المسرد؟ ← [ق-07](decisions.md#ق-07--فجوة-المسرد-وحزمة-اللغة)

### العربية في Markdown

- ابدأ كلَّ فقرةٍ وبندٍ بكلمةٍ عربيّة: GitHub يحدّد اتّجاه الفقرة بأوّل حرفٍ فيها. ويُستثنى من ذلك خليّةُ جدولٍ هي معرِّفٌ وحده، كمسارٍ أو وسم.
- ضع الكودَ والمساراتِ والأوامرَ بين علامتَي backtick دائمًا.
- فكرةٌ واحدةٌ في كلّ جملة. الأمرُ يبدأ بفعل: «شغّل…»، «انسخ…».
- التشكيلُ في النثر حيث يرفع لبسًا أو يُعين القراءة، ولا تشكيلَ في العناوين. والعريضُ لكلمةٍ واحدةٍ في الفقرة على الأكثر.
- الأرقامُ في السياق التقنيّ غربيّة، والتواريخُ بصيغة `2026-11-26`.
- كلُّ ⚠️ معه ما تفعله، لا التحذيرُ وحده.
- الجدولُ لعناصرَ متشابهةٍ لها صفات، بأربعة أعمدةٍ على الأكثر. والقائمةُ المرقّمة للخطوات.
