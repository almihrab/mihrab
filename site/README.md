# موقع محراب العربيّ

| | العنوان | مَن ينشر |
| --- | --- | --- |
| **الأصل** | <https://mihrab.dev/> | `build/deploy_site.sh` (‏tar عبر ssh إلى خادمنا) |
| المرآة | **غيرُ مفعَّلة** (‏`almihrab.github.io/mihrab/` ⇒ ‎404‎؛ السيرُ `docs-pages.yml` موجودٌ وPages غيرُ مفعَّلةٍ في إعدادات المستودع) | — |

الأصلُ على خادمنا لأنّ **الثنائيّات تسكن هناك**: حزمةُ محراب تقارب ٢٠٠ ميغابايت،
وGitHub Pages ليس مخزنَ ملفّات. والنطاقُ `mihrab.dev` نطاقُ محرابٍ المستقلّ: الجذرُ
هذا الموقع، و`app.mihrab.dev` محرابُ المتصفّح (أصلٌ منفصلٌ عمدًا). وإلى الجذر تشير
هويّةُ المنتج (`product-overrides/product.json`) و`rel=canonical` في كلّ صفحة. والمرآةُ تبقى لأنّ المولِّد واحد فلا انجراف، ولأنّها احتياطٌ مجّانيّ.

## البنية على الشبكة

المساراتُ على الأصل من الجذر، وعلى المرآة تحت `/mihrab/` — والمخرَجُ واحدٌ لأنّ كلَّ
رابطٍ فيه نسبيّ (يحرسه `check_site.py`):

```
/                 الصفحةُ الأولى — واجهةُ المنتج
/download/        التنزيل (يقرأ dl/releases.json الحيّ)
/dl/              الثنائيّات + releases.json  ← لا يمسّه النشر
/docs/            مركزُ التوثيق
/start/           صفحاتُ التوثيق — مساراتُها لم تتغيّر عمدًا
/keyboard/        (مخبوزةٌ في product.json وفي نسخٍ مشحونةٍ سلفًا)
/404.html         صفحةُ الخطأ — تخدمها كتلةُ `app.mihrab.dev` أيضًا بـ`alias`
```

## النشر

```bash
build/deploy_site.sh                       # الموقع → mihrab.dev
build/package_assets.sh win-x64-zip win-x64-setup   # مخرَجُ البناء → dist/Mihrab-<الإصدار>-<المعرّف>.<الامتداد>
build/publish_release.sh 1.121.05071 \
    win-x64-setup:dist/Mihrab-1.121.05071-win-x64-setup.exe \
    win-x64-zip:dist/Mihrab-1.121.05071-win-x64-zip.zip  # ثنائيّات → dl/ + مانيفستٌ حيّ
```

`package_assets.sh` يغلّف مخرَجَ `build.sh` بأسماء معرّفات `data/site.json` نفسِها — ويحرسه
**[PKG-01]**: لكلّ معرّفٍ في الصفحة فرعُ تغليف، فمنصّةٌ تُعلَن ولا تُبنى تحمرّ في L0 لا
عند الزائر. و`deploy_site.sh` يستثني `dl/` من `--delete` ويبدّل المجلّدَ ذرّيًّا، ولا يشحن
شاهدَ البناء `.mihrab-site-build`. و`publish_release.sh`
يحسب SHA-256 **على الخادم بعد الرفع** — البصمةُ تصف ما وصل لا ما غادر.

## مانيفستُ الإصدار — نسختان عمدًا

| | أين | مَن يكتبها |
| --- | --- | --- |
| الحيّة | `dl/releases.json` على الخادم | `publish_release.sh` |
| المخبوزة | `site/data/releases.json` | يدويًّا بعد النشر |

رفعُ بناءٍ جديد لا يستلزم إعادةَ بناء الموقع: الصفحةُ تجلب الحيَّ عند فتحها. والمخبوزةُ
تُبقيها صادقةً إن حُجب الجلب (بلا شبكة أو حاجبِ سكربتات) بدل جدولٍ فارغٍ بلا تفسير.
و`version: null` ⇒ حالةُ فراغٍ صريحة تحيل إلى البناء من المصدر — لا نَعِد بملفٍّ لا وجودَ له.

## لماذا مولِّدٌ لنا لا قالبٌ جاهز

دعمُ RTL في القوالب الجاهزة (Docsy · Just-the-Docs · Docusaurus) طبقةُ `[dir=rtl]`
مضافةٌ لاحقًا: تغطّي التخطيطَ ولا تغطّي الحالاتِ الحدّيّة — عزلَ bidi حول `Ctrl+Shift+P`،
واتّجاهَ انزلاق الدرج، وتخطيطَ الطباعة على عمودين. وهذه بالضبط الحالاتُ التي بُني
الموقعُ لأجلها. وترقيعُها أطولُ من كتابة ما نملك، وتفرض هويّةً بصريّة تناقض هويّة محراب.

## البناء

```bash
python site/build.py            # → site/public/
python site/build.py --check    # تحقّقٌ بلا كتابة
```

المخرَجُ في `.gitignore`: يُبنى في CI عند كلّ نشر. و`build.py` يمحو `site/public/` قبل الكتابة
**ولا يمحو إلّا ما بناه هو**: يترك شاهدًا `site/public/.mihrab-site-build`، وبلا الشاهد يرفض
المحوَ بصوتٍ — كي لا يمسح مجلّدًا ليس له. ويحرس ذلك **[OUT-01]** في `check_site.py`: ملفٌّ
بائتٌ من بناءٍ سابق لا ينجو البناءَ الجديد، والشاهدُ يُعاد كتابتُه بعد المحو.

## البنية

| المسار | ما فيه |
| --- | --- |
| `content/*.md` | الصفحاتُ المترجَمة، لكلٍّ ترويسةُ front-matter |
| `data/site.json` | نصُّ الصفحة الأولى + مصفوفةُ المنصّات + المتطلّبات |
| `data/releases.json` | المانيفستُ المخبوز (احتياطُ صفحة التنزيل) |
| `data/releases-alif.json` | مانيفستُ معاينة ألف (`preview/alif/`) |
| `data/keybindings.json` | مصدرُ صفحة الاختصارات |
| `data/glossary.json` | المسرد — مصدرُ الحقيقة للمصطلحات |
| `assets/mihrab-docs.css` | الرموزُ والأساسُ وصفحاتُ التوثيق |
| `assets/mihrab-home.css` | واجهةُ المنتج — مفصولةٌ كي لا يمسّ تعديلٌ تسويقيّ التوثيقَ |
| `assets/docs.js` | السمة، الدرج، البحث، صفحةُ الاختصارات |
| `assets/site.js` | تخمينُ النظام + جلبُ المانيفست الحيّ |
| `assets/fonts/` | الأوجهُ الأربعةُ المورَّدة + `OFL.txt` + README — يولّد منها `build.py` ورقةَ `fonts.css` |
| `assets/shots/editor.png` | لقطةُ الصفحة الأولى (اختياريّة — يسقط إلى رسمٍ SVG معلَن) |
| `build.py` | المولِّد |

النصُّ التسويقيّ في `data/site.json` لا في بايثون: تغييرُ جملةٍ يجب ألّا يمرَّ بمراجعةِ كود.

## الفحص

```bash
python tests/docs/check_site.py     # يبني ثمّ يفحص البنية — يحجب النشر في CI
```

يمسك ما لا تراه العين: مِرساةً يبحث عنها `site.js` ولا يجدها فيموت السلوكُ صامتًا،
ومفتاحًا في `product.json` يشير إلى صفحةٍ لا تُبنى، ورابطَ تنقّلٍ مطلقًا يكسر المرآة.
ومعه **[CSS-01]**: تعليقٌ مبتورٌ أو نصٌّ طليقٌ داخل `:root` في أوراق `assets/` يبتلع
الإعلانَ الذي يليه بلا خطأٍ من المتصفّح — وقع فعلًا فعُرض الموقعُ كلُّه بخطّ النظام
وكلُّ حارسٍ أخضر. و**[W404]**: صفحةُ ‎404‎ تُقدَّم من الأصلين فأصولُها مطلقةٌ على أصل الموقع.

## الترويسة الإلزاميّة لكلّ صفحة

```yaml
---
description: سطرٌ واحد للفهرسة والبحث.
source_path: docs/editing/codebasics.md    # صفحةُ المنبع (شرطُ النِسبة في CC BY)
translated_at: 2026-08-01
source_sha: "…"                            # بصمةُ ملفّ المنبع وقتَ الترجمة
---
```

`source_sha` تُملأ آليًّا:

```bash
python tests/docs/check_drift.py --seed     # يبذر البصمةَ للصفحات الخالية منها
python tests/docs/check_drift.py            # يقارن بالمنبع ويرفع رايةَ الانجراف
python tests/docs/check_drift.py --offline  # اكتمالُ البيانات فقط، بلا شبكة
```

بلا هذا تموت الترجمةُ صامتةً: تُترجَم مرّةً، ثمّ يتغيّر المنبع، فتبقى **تكذب بثقة**
— وهي حينئذٍ أسوأُ من غيابها.

## تعليمُ Markdown المدعوم

مجموعةٌ فرعيّة مضبوطة: عناوين `##`/`###`، فقرات، قوائم، جداول، كتلُ كودٍ مسيَّجة،
كودٌ سطريّ، روابط، `**عريض**`. وما عداها يُرفَض صراحةً لا يُتجاهَل صامتًا.

وزيادةٌ واحدة خاصّة بنا — **الاختصار**:

```
{{Ctrl+Shift+P}}
```

تُصيَّر حاويةً معزولةً اتّجاهيًّا (`unicode-bidi: isolate`). لا تكتب الاختصارَ نصًّا
عاديًّا داخل جملةٍ عربيّة: خوارزميّةُ bidi تنقل علامةَ `+` أو تعيد ترتيبَ الرموز
المجاورة، فيعرض الموقعُ `Ctrl+Shift+P` خطأً.

## المصطلحات

كلُّ مصطلحٍ من `data/glossary.json`، وفحصُ L0 يمسك البدائلَ الممنوعة. السببُ أنّ
توثيقًا يقول «لوحة الأوامر» وواجهةً تقول «لوحة الأوامر السريعة» **أسوأُ من توثيقٍ
إنجليزيّ**: يُشكِّك المستخدمَ في فهمه هو.

**والفجوةُ بين المسرد وحزمة اللغة مقيسةٌ لا مفترَضة** — **[GLS-02]** في
`tests/static/lint_patchers.py` يعدّ الألفاظَ الممنوعةَ التي تعرضها `language-pack-ar`
المورَّدةُ فعلًا (‏«الإضافة» و«التصحيح» وأخواتُهما، كلماتٍ كاملةً) مقابلَ خطٍّ أساسٍ مثبَّت:
ترقيةُ حزمةٍ تزيدها تحمرّ، وملحقٌ يُنقِصها يُحدِّث الخطَّ نزولًا. والتعارضُ نفسُه موصوفٌ
في مفتاح `_gap` بالمسرد، وحسمُه قرارُ منتجٍ لا يملكه الحارس. وحتّى يُحسَم، قاعدةُ الكتابة:
اسمُ أمرٍ أو زرٍّ أو تبويبٍ يُقتبَس **كما تعرضه الشاشةُ حرفًا** بين «» مع «(هكذا اسمُه في
الواجهة)»، والنثرُ من حوله بلفظ المسرد — فلا يبحث القارئُ عن زرٍّ لا وجودَ له.

## الخطوط

**مورَّدةٌ ومُودَعة** — أربعةُ أوجهٍ من IBM Plex Sans Arabic (‏SIL OFL 1.1) في
`assets/fonts/`، وتفصيلُها ومصدرُها وبصماتُها في
[`assets/fonts/README.md`](assets/fonts/README.md).

```
plex-arabic-400 · plex-arabic-600 · plex-latin-400 · plex-latin-600   (128.2 ك.ب)
```

**ولماذا أربعةٌ لا ثلاثة؟** كان المطلوبُ مكتوبًا هنا «‏arabic‑400 · arabic‑600 ·
**mono**‑400». فتبيّن عند التوريد أنّ ملفَّي العربيّة **لا يحملان حرفًا لاتينيًّا
واحدًا** — التقليمُ يفصل المدَيَين — فكلُّ رقمٍ و`mihrab.dev` وكلُّ كودٍ يسقط إلى
خطّ النظام: السطرُ الواحدُ بخطَّين، وهو **أسوأُ من عدم التوريد**. فجُلِب النظيران
اللاتينيّان. وأُسقِط `plex-mono` لأنّه **بلا محارفَ عربيّةٍ هو الآخر** — فتوريدُه
لا يُصلِح اختلاطَ الخطّين في `.محراب/settings.json` ولا في `اطبع "السلام عليكم"`،
والعلاجُ هناك اسمُ عائلةٍ ثانٍ على الوجهَين العربيَّين (انظر README المجلّد).

ويولّد `build.py` كتلَ `@font-face` **للموجود فعلًا وحده** مع `unicode-range` لكلّ
وجه، وينسخ `OFL.txt` و`README.md` إلى المخرَج معها. و`unicode-range` **شرطُ عملٍ لا
تحسينُ أداء**: وجهان بالعائلة والوزن نفسِهما وبلا مدًى يتنازعان فيأخذ المتصفّحُ
الأخيرَ ويهمل الأوّل.

ويحرس ذلك كلَّه **[FNT-01]** في `tests/docs/check_site.py`: كلُّ وجهٍ تَعِد به
`FONT_FACES` مُعلَنٌ وموجودٌ وغيرُ مبتورٍ ومطابقُ البصمة، والمدَيان بلا تداخل،
و**كلُّ محرفٍ يراه الزائرُ** — في المتن وفي السمات المعروضة وفي `content:` بأوراق
الأنماط، والكياناتُ مفكوكةٌ لا ممحوّة — داخلَ المدَيَين أو على قائمةٍ بيضاءَ كلُّ
بندٍ فيها بتعليلٍ مكتوب. ونصُّ الرخصة يصل المخرَجَ مع الملفّات بهويّته لا بطوله.
وترويسةُ `Access-Control-Allow-Origin` لازمةٌ على
كتلة الخطوط: صفحةُ ‎404‎
مشتركةٌ بين الأصلين، فجلبُ الخطّ عابرُ أصلٍ يسقط صامتًا بلا تلك الترويسة.
