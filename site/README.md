# موقع محراب العربي

هذا مولِّدُ الموقع <https://mihrab.dev/> ومحتواه: الصفحةُ الأولى، والتنزيل، ومركزُ التوثيق.
يُبنى بمولِّدٍ لنا في بايثون، ويُنشَر على خادمنا (التفاصيل في [النشر](guide/deploy.md)).

## بداية سريعة

```bash
python site/build.py                      # يبني الموقع في site/public/
python site/build.py --check              # يتحقّق بلا كتابة
python tests/docs/check_site.py           # يبني ثمّ يفحص؛ يحجب النشرَ وCI
python -m http.server -d site/public      # معاينةٌ على http://localhost:8000/
```

المعاينةُ تحتاج خادمًا محلّيًّا: البحثُ يجلب `search-index.json`، والمتصفّحُ يمنع الجلبَ من `file://`.

## خريطة الملفات

| المسار | ما فيه |
| --- | --- |
| `content/*.md` | صفحاتُ التوثيق المترجَمة، لكلٍّ منها ترويسة |
| `data/site.json` | نصُّ الصفحة الأولى، ومصفوفةُ المنصّات، والمتطلّبات |
| `data/glossary.json` | المسرد: مصدرُ الحقيقة للمصطلحات |
| `data/keybindings.json` | مصدرُ صفحة الاختصارات |
| `data/releases.json` | المانيفستُ المخبوز، احتياطُ صفحة التنزيل |
| `data/releases-alif.json` | مانيفستُ معاينة ألف (`preview/alif/`) |
| `assets/mihrab-docs.css` | الرموزُ والأساسُ وصفحاتُ التوثيق |
| `assets/mihrab-home.css` | الصفحةُ الأولى، مفصولةٌ كي لا يمسّ تعديلٌ تسويقيّ التوثيقَ |
| `assets/docs.js` | السمة، والدرج، والبحث، وصفحةُ الاختصارات |
| `assets/site.js` | تخمينُ نظام الزائر، وجلبُ المانيفست الحيّ |
| `assets/icon.svg` | أيقونةُ الموقع |
| `assets/fonts/` | الخطوطُ المورَّدة ورخصتُها ([README](assets/fonts/README.md)) |
| `assets/shots/editor.png` | لقطةُ الصفحة الأولى، اختياريّة: تغيب فيظهر رسمٌ بديل |
| `build.py` | نقطةُ الدخول: يجمع الصفحات، ويمحو المخرَج، ويكتبه |
| `sitegen/data.py` | المسارات، وقراءةُ `data/`، والتنقّل (`NAV`) |
| `sitegen/text.py` | Markdown المضبوط، والترويسة، ونصُّ فهرس البحث، وبدائلُ المسرد |
| `sitegen/templates.py` | الترويسةُ العليا، والتنقّل، والفهرس، والتذييل، وغلافُ الصفحة، و`data_island` |
| `sitegen/pages.py` | الصفحاتُ بلا ملفّ محتوى: الأولى، والتنزيل، والاختصارات بترتيب معدِّلاتها، و404 |
| `sitegen/fonts.py` | نطاقا المحارف، و`FONT_FACES`، وكتابةُ `fonts.css` |
| `sitegen/strip.py` | تجريدُ تعليقات CSS وJS وقتَ البناء |
| `sitegen/preview.py` | صفحةُ معاينة «محراب × ألف» |
| `guide/` | هذا الدليل. لا يدخل البناء |

أضفتَ ملفًّا أو وحدة؟ أضف صفَّها هنا في الطلب نفسه.

⚠️ لا تضع ملفَّ بايثون آخرَ في جذر `site/`: مجلّدُ `build.py` أوّلُ `sys.path`، فملفٌّ مثل `site/json.py` يظلّل المكتبةَ القياسيّة. ضعه في `sitegen/` ([DET-01](guide/checks.md#بنية-المولد-والمخرج)).

المسردُ والاختصاراتُ تصل لوحةَ المساعدة في المحرّر آليًّا: يولّدها `build/lib/help_data.py` في امتداد الترحيب عند كلّ بناء، ولا تُحفَظ فيه نسخةٌ ثانية ([ON-03](guide/checks.md#حراس-من-خارج-الموقع)).

## مسارات الموقع على الشبكة

```
/                 الصفحةُ الأولى
/download/        التنزيل (يقرأ dl/releases.json الحيّ)
/dl/              الثنائيّات و releases.json ← يرفعها publish_release.sh
/docs/            مركزُ التوثيق
/start/ …         صفحاتُ التوثيق، بمساراتٍ ثابتةٍ عمدًا
/keyboard/        (مخبوزةٌ في product.json وفي نسخٍ شُحنت سلفًا)
/404.html         صفحةُ الخطأ، تخدمها كتلةُ app.mihrab.dev أيضًا بـ alias
```

وما يفعله النشرُ بـ`dl/` في [انشر الموقع](guide/deploy.md#انشر-الموقع).
والمخرَجُ يصلح تحت أيّ بادئة، لأنّ كلَّ رابطٍ فيه نسبيّ ([ق-02](guide/decisions.md#ق-02--روابط-نسبية-فقط)).

## حرر هذا الدليل

- **مالكٌ واحد:** لكلّ معلومةٍ ملفٌّ واحدٌ يملكها، والباقي يحيل إليه.
- **ما يملكه الكود:** الأعدادُ والأحجامُ والبصماتُ لا تُكتب في النثر. أحِل إلى موضعها.
- **التعليل:** مكانه [القرارات](guide/decisions.md)، والإرشادُ سطرٌ ورابط «لماذا؟».
- **قالبُ المهمّة:** عنوانٌ بفعل أمر، ثمّ «متى» أو «يلزمك»، ثمّ خطواتٌ مرقّمة، ثمّ «تحقّق»، ثمّ ⚠️ معها الفعل، ثمّ «لماذا؟ ← ق-NN».
- **الأسلوب:** قواعدُ الكتابة بالعربيّة في [كتابة المحتوى](guide/authoring.md#العربية-في-markdown).
- **الروابط:** نسبيّةٌ إلى عنوانٍ لا إلى رقم سطر. وبعد تغيير عنوانٍ حدّث ما يشير إليه.
- **العناوين:** بلا تشكيلٍ ولا شدّة، فتُكتب مراسيها بلا تخمين.
- **التقسيم:** صفحةٌ في `guide/` صارت لقارئَين مختلفَين؟ قسّمها، وأضف لكلّ قسمٍ صفًّا في «أين تبدأ».
